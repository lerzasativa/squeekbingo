1. Watch the live wheel

The game polls the Squeekchain status API every 5 seconds. Your card holds 24 real wheel events — run starts and stops, RPM and speed thresholds, work and distance milestones, new blocks, settled rounds, and oracle closures.

2. Events mark your card

When an event genuinely happens — say settledThroughRound ticks up or the hamster starts running — its square lights up. With auto-mark on it is stamped for you; turn auto-mark off to tap glowing squares yourself. The center square is free: SQUEEK!

3. Complete a line = BINGO

Fill 5 squares in a row — across, down, or diagonal — to win. Fewer live events to bingo means a bigger score bonus. A full card earns an extra bonus. If the API goes offline, the game says so honestly and pauses — it never invents events.

SqueekBingo — a game project for Squeekchain Genesis, built for submission to the Builder badge “The Buildooooor”. Live data: api.squeekchain.com/v1/status, polled every 5 seconds. Submit a project: squeekchain.com/genesis/code · Solo play, no wallet & no cost.
